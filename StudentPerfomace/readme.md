# Student Performance Prediction

Este projeto foi feito apenas para passar o tempo e praticar conceitos de Machine Learning.

Não possui objetivo acadêmico, comercial ou de produção.  
Foi usado apenas como exercício.

- Python
- Pandas
- Scikit-learn
- XGBoost
